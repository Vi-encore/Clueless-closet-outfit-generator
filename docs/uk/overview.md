# Застосунок коротко: екрани й функції

Зведення всього, що заплановано. Деталі — за посиланнями.

## Що це

Цифровий гардероб у стилі комп'ютера Шер із «Clueless»: фотографуєте свої речі, обираєте нагоду — застосунок підбирає образ і показує його на 2D-ляльці. Працює на телефоні й комп'ютері (PWA), у кожного користувача свій акаунт і гардероб, можна дружити й листуватися.

## Головний цикл

```
додати речі → обрати нагоду → образ на ляльці → «вдягнула сьогодні» → щоденник і статистика
                                    ↑                                         │
                                    └── лайки, «ще варіант», історія ─────────┘
```

Генератор враховує, що і коли вдягалося, та ваші лайки, тож з часом образи стають точнішими.

## Як виглядає

Windows 98 з акцентами «Clueless»: сірі об'ємні вікна, рожеві заголовки, жовта клітинка Шер на робочому столі, вердикт «MATCH!» піксельними літерами. Деталі стилю й бібліотек — [ui.md](ui.md).

- **Телефон:** кожен екран — вікно на весь екран; знизу — панель задач: «Пуск» + основні розділи + годинник і значок нових повідомлень. «Пуск» відкриває меню з рештою розділів.
- **Комп'ютер:** робочий стіл з ярликами, вікна по центру. Пізніше — кілька вікон поруч (гардероб + лялька) і перетягування.

Екран «Образ дня» на телефоні (ескіз):

```
┌──────────────────────────────┐
│ Образ дня              [?][x]│  ← заголовок вікна
├──────────────────────────────┤
│ Нагода: [Робота       v]     │
│ ┌────────────┐  Колір   ████ │
│ │    (  )    │  Силует  ███░ │  ← бали за компонентами
│ │   блуза    │  Стиль   ██░░ │
│ │   штани    │               │
│ │   туфлі    │   MATCH!      │  ← вердикт
│ └────────────┘               │
│ [Лайк] [Ні]  [Ще варіант]    │
│ [Вдягнула сьогодні]          │
├──────────────────────────────┤
│[Пуск] Гардероб Образ Чат 9:41│  ← панель задач
└──────────────────────────────┘
```

## Екрани й функції (PoC)

| Екран | Що там | Крок |
|---|---|---|
| **Вхід / реєстрація** | Email і пароль | 4, 8 |
| **Гардероб** | Сітка вирізаних фото; фільтри (слот, сезон, колір, статус), пошук; кнопка «Додати річ» | 5, 8 |
| **Додати річ** | Камера або галерея → видалення фону → форма тегів. Спершу вручну, згодом AI заповнює наперед ([auto-tagging.md](auto-tagging.md)); обов'язкові лише категорія і тип | 9, 15 |
| **Картка речі** | Фото, теги, скільки разів вдягалась; дії: редагувати, «в прання», «образ з цією річчю», архівувати з причиною | 5, 10 |
| **Образ дня** | Нагода → образ на ляльці + бали; лайк / «ні» / «ще варіант» / зберегти / «вдягнула сьогодні» | 10 |
| **Підгонка на ляльці** | Перетягнути й масштабувати річ на манекені один раз — далі вона сідає сама ([try-on.md](try-on.md#етап-0-2d-лялька)) | 10 |
| **Збережені образи** | Список збережених і лайкнутих | 10 |
| **Друзі й чат** | Пошук за `username`, запити в друзі, розмови наживо | 6, 8 |
| **Щоденник** | Календар «що вдягалося», фото себе в образі, «рік тому ви вдягали…» | 12 |
| **Статистика** | Вартість одного вдягання, «давно не вдягалося — віддати?», розподіл за кольорами й категоріями | 13 |
| **Налаштування** | Ім'я, часовий пояс, вийти | 8 |
| **Мій манекен** | Основа ляльки: стандартний манекен, манекен за вашими мірками або своє фото ([try-on.md](try-on.md#манекен-за-вашими-параметрами)) | 10, 14 |

Системні нагоди (робота, щодня, вечірка, побачення, спорт, дім, подорож) — з кроку 10.
