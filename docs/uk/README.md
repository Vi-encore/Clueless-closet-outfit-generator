## Прийняті рішення

- **Клієнт:** PWA (React + Vite + TS) — працює і на телефоні, і на комп'ютері.
- **Інтерфейс:** Windows 98 з акцентами «Clueless»; 98.css + Tailwind CSS, власні компоненти. Див. [ui.md](ui.md).
- **Бекенд:** NestJS — заради практики.
- **База:** PostgreSQL на Neon, ORM Prisma.
- **Файли:** S3-сумісне сховище (Cloudflare R2; код сумісний з AWS S3).
- **Користувачі:** багато; у кожного свій акаунт і гардероб.
- **Proof of concept — без витрат і без картки:** локально на ПК + Neon + Backblaze B2 + тунель для телефона. Див. [poc.md](poc.md).
- **Try-on:** MVP — 2D-«лялька» з вирізаних фото; далі — відкрита модель (CatVTON) на Modal ($30 кредитів / міс, потрібна картка + ліміт витрат). Запасні варіанти — локальна GPU або платний Gemini.
- **Автотеги:** Gemini free tier на час розробки або локальна vision-модель.

## Відкриті питання

- [ ] **Склад образу в MVP.** Верх + низ і сукні — точно. Взуття, верхній одяг, аксесуари — одразу чи пізніше?
- [x] **Картка.** Для PoC — без картки ([poc.md](poc.md)). До R2 / Modal повертаємось після PoC ([backend-options.md](backend-options.md#чи-потрібна-картка)).
- [ ] **Якість try-on.** Перевірити CatVTON на своїх фото (публічне демо на Hugging Face); для порівняння — Nano Banana в AI Studio.
- [ ] **Добовий ліміт примірок** на користувача.
- [ ] **Позичання.** Позичати можна будь-кому за username чи лише друзям?
- [x] **Стиль інтерфейсу.** Windows 98 + акценти «Clueless»; зручність на телефоні важливіша за точність відтворення ([ui.md](ui.md)).
- [ ] **98 чи XP; який піксельний шрифт.** Вирішити до кроку 8 на [порівняльній сторінці](https://claude.ai/artifact/T4sE66Mi9oaWWaxnNZtr9Q), зокрема на телефоні. Рекомендація — 98 ([ui.md](ui.md#альтернативи)).
- [ ] **MATCH! / MIS-MATCH.** Коли показувати вердикт: поріг загального балу чи окремі перевірки поєднання?
- [ ] **Погода.** Враховувати в MVP чи пізніше?
