# Інтерфейс: стиль і бібліотеки

## Стиль

- **Основа — Windows 98:** сірі вікна з об'ємними рамками, заголовки з градієнтом, «натиснуті» кнопки, панель задач із «Пуском».
- **Акценти «Clueless»:**
  - робочий стіл — жовта клітинка Шер (CSS-градієнти, без картинки);
  - градієнт заголовків вікон — рожево-фіолетовий замість синього;
  - вердикт образу великими піксельними літерами: «MATCH!» або червоне «MIS-MATCH». Як саме його рахувати — відкрите питання ([README](README.md#відкриті-питання)).
- **Зручність на телефоні важливіша за точність відтворення:** більші кнопки, читабельний текст. Леопард і інші теми — пізніше.

Як це виглядає в застосунку — [overview.md](overview.md#як-виглядає).

## Рекомендація: 98.css + Tailwind CSS

| Що | Роль |
|---|---|
| [98.css](https://jdan.github.io/98.css/) (v0.1.21, MIT) | Ретро-вигляд. Лише CSS, без JS: стилізує звичайні елементи (`button`, `input`, `select`, `fieldset`, вкладки `menu[role=tablist]`, дерево `ul.tree-view`) і класи вікна (`.window`, `.title-bar`, `.window-body`, `.status-bar`) |
| [Tailwind CSS](https://tailwindcss.com/) v4 | Розкладка: flex / grid, відступи, адаптивність (`md:`), safe area. Кольори й рамки елементів — робота 98.css, Tailwind їх не чіпає |
| Власні компоненти | `Window`, `Taskbar`, `StartMenu`, `Chips`, `Dialog` — невеликі обгортки над класами 98.css |

**Чому саме так:**
- немає JS, тож немає й проблем сумісності з версією React;
- форма тегів одразу виглядає ретро — це звичайні `input` і `select`;
- компоненти невеликі, а писати їх — корисна практика React і доступності;
- повний контроль над телефонною версією.

## Як поєднати 98.css і Tailwind

Tailwind v4 розкладає стилі по каскадних шарах: `theme → base → components → utilities`. **Стилі поза шарами завжди перемагають стилі в шарах, незалежно від специфічності.**

Тому 98.css треба підключити в шар `components`, а не звичайним `import "98.css"` у `main.tsx`:

```css
/* apps/web/src/index.css */
@import "tailwindcss";
@import "98.css/dist/98.css" layer(components);
@import "./retro.css" layer(components); /* наші доповнення */
```

- 98.css у `components` перебиває reset Tailwind (`base`), а утиліти перебивають 98.css: `className="px-4"` на кнопці спрацює.
- Якщо 98.css опиниться поза шарами, він перебиватиме утиліти, і `px-4` мовчки не працюватиме.
- `retro.css` — наші доповнення: тема «Clueless», сенсорні розміри, шрифти. Він у тому самому шарі, але після 98.css, тож перемагає за рівної специфічності.

## Шрифт і кирилиця

- **Піксельний шрифт 98.css і XP.css не має жодної кириличної літери** (перевірено: 116 символів, лише латиниця). Українські написи впадуть у запасний Arial, і вийде суміш шрифтів.
- **Рішення:**
  - піксельний шрифт з кирилицею — для заголовків вікон, кнопок і акцентів;
  - звичайний читабельний шрифт — для основного тексту й полів: дрібний піксельний текст на телефоні читається погано.
- **Піксельні шрифти Google Fonts з кирилицею** (перевірено):

  | Шрифт | Сітка | Особливості |
  |---|---|---|
  | **Press Start 2P** | 8 px | Звичні форми літер, дуже чіткий, але дуже широкий — для «MATCH!», заголовків, коротких написів |
  | **Tiny5** | 8 px | Вузький і компактний — кандидат для кнопок і заголовків вікон |
  | **Pixelify Sans** | немає | Лише «під піксель»: масштабується плавно, але ніде не ідеально чіткий; кирилична «д» — у рукописній формі, схожа на «∂» |

- **Шрифт на сітці 8 px чіткий лише на 16, 24, 32 px.** На 12 чи 20 px пікселі розмиваються, і літери стають схожими одна на одну. Тому розміри в темі — кратні 8.
- Без кирилиці: VT323, Silkscreen, Jersey 10.
- **Порівняльна сторінка** (приватна): https://claude.ai/artifact/T4sE66Mi9oaWWaxnNZtr9Q — 98 / XP, чотири шрифти, ескізи «Образ дня» і «Нова річ». Відкривати й на телефоні.
- **Підключення — через [Fontsource](https://fontsource.org/)** (`@fontsource/pixelify-sans`): шрифт лежить у вашому білді, тож працює офлайн у PWA й не залежить від Google.

## Телефон

- **Кожен екран — вікно на весь екран**, без зовнішньої рамки й тіні; ✕ у заголовку означає «назад».
- **Панель задач** знизу з відступом `env(safe-area-inset-bottom)`.
- **Сенсорні розміри.** У 98.css кнопка 23 px заввишки, шрифт 11 px — розраховано на мишку. У `retro.css` для `@media (pointer: coarse)`:
  - кнопки й поля — ≥ 44 px;
  - шрифт полів — ≥ 16 px, інакше iPhone збільшує сторінку при фокусі ([mobile.md](mobile.md));
  - чекбокси й радіокнопки — більші.
- **На hover не покладатися:** на телефоні його немає.

## Комп'ютер

- Робочий стіл з ярликами (Гардероб, Образ дня, Щоденник…) і вікна.
- **PoC:** одне активне вікно по центру.
- **Пізніше:** кілька вікон поруч (гардероб + лялька), перетягування (напр. `@neodrag/react`), «згорнути» в панель задач.
- **Роутинг звичайний (React Router):** «вікно» — лише оформлення сторінки. Тому посилання, кнопка «назад» і телефонна версія працюють без хитрощів.

## Тема «Clueless»

- У 98.css немає CSS-змінних: кольори вшиті прямо в правила. Тому тему робимо так: у `retro.css` оголошуємо власні змінні в `:root` і перевизначаємо кілька правил 98.css, наприклад фон `.title-bar`.
- Жовта клітинка робочого столу — кілька шарів `repeating-linear-gradient`.
- **Темна тема:** у Windows 98 її не було. У PoC не робимо; пізніше — окрема «нічна» тема через ті самі змінні.
