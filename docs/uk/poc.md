# Proof of concept: без витрат і без картки

## Принцип

Для proof of concept хмара не потрібна: усе працює на власному ПК, а телефон під'єднується через безкоштовний тунель. Код пишемо через абстракції (`StorageService` на S3 API, `TryOnProvider`), тож пізніше перехід на R2, Modal чи хостинг — це зміна налаштувань, а не переписування.

## Складові

| Що | PoC (без картки) | Потім (коли з'явиться бюджет) |
|---|---|---|
| База | Neon (без картки) або Postgres у Docker | Neon |
| Файли | Backblaze B2 (10 ГБ, без картки, S3 API) | R2 або B2 |
| API (NestJS) | Локально на ПК | Render / VPS |
| Клієнт (PWA) | Vite dev server на ПК | Cloudflare Pages / Netlify / Vercel |
| Доступ з телефона | Cloudflare Quick Tunnel — HTTPS-адреса `*.trycloudflare.com`, без акаунта | Власний домен / хостинг |
| Автотеги | Gemini free tier (потрібен лише Google-акаунт) або вручну | Gemini, платний тариф |
| Try-on | 2D-лялька; AI — див. [нижче](#try-on-без-картки) | Modal або Gemini |

### Доступ з телефона через тунель

```bash
cloudflared tunnel --url http://localhost:5173
```

- Дає HTTPS-адресу. Це важливо: встановлення PWA й доступ до камери на телефоні потребують HTTPS.
- **Один тунель на все:** Vite проксює `/api` на Nest (`server.proxy`), тож клієнт і API доступні з однієї адреси й не треба налаштовувати CORS під нову адресу.
- Vite блокує невідомі хости — додати `server.allowedHosts: ['.trycloudflare.com']`.
- Адреса змінюється при кожному запуску; тунель живе, доки працює команда. Лише для тестів і демо, без гарантій доступності.

## Try-on без картки

| Варіант | Обмеження | Роль у PoC |
|---|---|---|
| 2D-лялька (canvas) | Немає | Основний спосіб показати образ |
| Публічне демо CatVTON / IDM-VTON на Hugging Face, виклик з Nest через `@gradio/client` | Безкоштовний акаунт — кілька хвилин GPU на день; демо може зламатися чи зникнути; фото йдуть на чужий сервер | Кілька AI-примірок на своїх фото для «вау-ефекту» |
| Google Colab / Kaggle (безкоштовна GPU в ноутбуці) | Обмежені сесії, не сервер | Перевірити якість CatVTON без встановлення на ПК |
| Локально на RTX 4070 Ti SUPER | Без лімітів | Коли захочеться; ComfyUI Desktop має інсталятор для Windows |

У Nest це реалізації одного інтерфейсу `TryOnProvider`: для PoC — `HuggingFaceSpaceProvider`, пізніше — `ModalProvider`, `LocalProvider` чи `GeminiProvider`.

## Що PoC має показати

- Додати 10–20 своїх речей з телефона: фото → видалення фону → теги.
- Згенерувати образи для 3–4 нагод і оцінити, чи алгоритм дає адекватні поєднання.
- Показати образ 2D-лялькою.
- (Опційно) 2–3 AI-примірки через публічне демо.
- Два акаунти — перевірити, що користувачі не бачать речей одне одного.

## Обмеження PoC

- Працює, лише коли ПК увімкнений і запущені API, клієнт і тунель.
- Адреса тунелю змінюється при кожному запуску.
- Дані в Neon і B2 — у справжніх хмарних сервісах, тож переживуть перехід від PoC до повноцінної версії.
