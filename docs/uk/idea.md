# Ідея

## Суть

Цифровий гардероб, який щоранку відповідає на питання «що вдягнути?».

1. Кожна річ у гардеробі сфотографована, вирізана з фону й описана тегами (колір, фасон, тканина, формальність, для яких нагод).
2. Обираєш нагоду — застосунок перебирає можливі поєднання, відкидає недоречні, оцінює решту й пропонує один із найкращих образів (не щоразу той самий).
3. Образ можна «приміряти»: згенерувати зображення себе в цьому одязі.

Настрій інтерфейсу — ретро-комп'ютер 90-х, як у Шер у «Clueless», але зручний на телефоні: Windows 98 з акцентами фільму ([ui.md](ui.md)). Усі екрани й функції коротко — в [overview.md](overview.md).

## Для кого

Для будь-кого, хто зареєструється: у кожного свій акаунт і свій гардероб, доступний з телефона й комп'ютера. Першим користувачем буде автор проєкту.

## Основні сценарії

1. **Додати річ.** Фото з телефона → автоматично прибирається фон → AI пропонує теги → перевірити й зберегти.
2. **Отримати образ.** Обрати нагоду (робота, щодня, вечірка, побачення, аеропорт…) → образ → «ще варіант» / зберегти / «не подобається» / «вдягнуто сьогодні».
3. **Приміряти.** Натиснути «приміряти» → анімація сканування → зображення себе в цьому образі.
4. **Гардероб.** Переглядати речі, фільтрувати, позначати «в пранні».
5. **Керування речами.** Архівувати з причиною (застаріла, віддана, продана); позичити іншій людині — з акаунтом у застосунку чи без нього.
6. **Історія.** Що і коли вдягалося; збережені образи.

## Обсяг MVP (по етапах)

**Етап 1 — акаунти й гардероб**
- реєстрація / вхід
- додавання речі: фото → видалення фону → теги (спершу вручну, потім AI)
- список речей з фільтрами, статуси «в пранні» / архів

**Етап 2 — генератор**
- нагоди (системні + власні, зі своїми правилами)
- алгоритм підбору: верх + низ, сукні / комбінезони
- «ще варіант», збереження, лайк / дизлайк, «вдягнуто сьогодні»
- показ образу 2D-«лялькою»: вирізані фото речей на силуеті, без AI

**Етап 3 — try-on**
- завантаження референсних фото себе
- відкрита модель (CatVTON) на Modal (serverless GPU)
- кешування результатів, добові ліміти

**Пізніше**
- позичання речей і друзі (див. [data-model.md](data-model.md#itemloan-пізніше))
- соціальне між друзями: чат щодо позичання, «порадь образ» з голосуванням, обране, оцінки (див. [social.md](social.md))
- погода (Open-Meteo — безкоштовно, без ключа)
- взуття, верхній одяг, аксесуари як додаткові шари образу
- «не повторювати образ N днів», статистика «що давно не вдягалося»
- капсульний гардероб, збирання валізи в подорож
- ваги алгоритму, що підлаштовуються під лайки / дизлайки
- вхід через Google

## Банк ідей

Не зобов'язання, а запас на майбутнє. У дужках — чого навчить.

| Ідея | Суть | Чого навчить |
|---|---|---|
| **Перевірка перед покупкою** → [features.md](features.md#перевірка-перед-покупкою) | Сфотографувати річ у магазині → «з чим вона поєднається у вашому гардеробі» + «у вас уже 5 схожих чорних футболок» | Перевикористання генератора для тимчасової речі, пошук схожих |
| **Валіза в подорож** → [features.md](features.md#валіза-в-подорож) | Дати + місто → прогноз погоди → мінімум речей, що дають максимум образів | Цікава оптимізаційна задача, зовнішні API |
| **Капсула** | Обрати 10–15 речей → скільки образів вони дають, чого бракує | Комбінаторика |
| **План на тиждень** | Календар образів з погодою; «образ дня» зранку push-сповіщенням | Заплановані задачі (cron), Web Push |
| **Статистика гардероба** → крок 13 [дорожньої карти](roadmap.md) | Вартість одного вдягання (ціна / кількість), «не вдягалося пів року — віддати?», розподіл за кольорами | SQL-агрегації, графіки |
| **Щоденник образів (OOTD)** → крок 12 [дорожньої карти](roadmap.md) | Фото себе в образі дня → календар; «рік тому ви вдягали…» | Робота з датами, галерея |
| **Прання й сезони** | Автостатус «в пранні» після N вдягань (джинси — після 4); «на зберіганні» для не сезонних речей | Правила й фонові задачі |
| **Додати річ зі скріншота магазину** | Фото товару вже на білому фоні — видалення фону майже ідеальне | — (швидкий виграш) |
| **Етикетка догляду** | Сфотографувати бирку → склад тканини в теги | Розпізнавання тексту в браузері (Tesseract.js) |
| **Челенджі** | «30 днів без повторів», «тиждень з однією річчю» | Геймифікація, прогрес |
| **Ретро-режим** | Звуки інтерфейсу 90-х, «MIS-MATCH», піксельні рамки | Анімації, Web Audio |

## Поки не робимо
